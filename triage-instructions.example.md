# Example Triage Instructions

This file is intentionally generic. Replace it with repository-specific
guidance before running against a real project.

- Classify only from evidence in the issue and the local repository checkout.
- Use only labels listed in `scheduler.toml`.
- Prefer a short, factual public comment over speculation.
- If the issue appears security-sensitive, mark it blocked and do not post
  technical details publicly.
- Do not make code changes from the triage workflow.
